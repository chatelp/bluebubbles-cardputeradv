Système

Même mécanique que les symboles de Geek Casino : un générateur Python est la source de vérité, l'en-tête C++ et cette carte en sortent ensemble. Palette indexée RGB565, 0 = transparent, 6048 octets d'art en flash. Les variantes fusionnent (😀😃😄 → un glyphe, tous les cœurs partagent une forme) ; les sélecteurs de variation, tons de peau et séquences ZWJ sont absorbés ; tout émoji inconnu devient le glyphe « ? » plutôt qu'un carré vide.
